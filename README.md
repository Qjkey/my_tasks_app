# Планер — Telegram Mini App

Список задач по дням недели + вкладка «Огонёк».  
Стек: **HTML / CSS / JS**, хостинг **Cloudflare Pages**, данные в **Cloudflare KV**.

## Маркеры задач

```text
(понедельник)
[] { каждый день }
[x] { один раз в этот день }
[xx] { каждую неделю в этот день }
[{}] { каждый день + подзадачи }
    - { подзадача }
[{x}] { один раз + подзадачи }
[{xx}] { еженедельно + подзадачи }
```

Кириллическая `х` в маркерах тоже поддерживается (`[х]`, `[хх]`, `[{х}]`…).

## Куда вводить код задач (варианты)

| Способ | Как | Когда удобно |
|--------|-----|--------------|
| **1. В приложении** | Кнопка «редактировать» (карандаш) → **«Код задач»** → вставить текст → Сохранить | Основной способ, пишется в KV |
| **2. Файл `tasks.example.txt`** | Лежит в репозитории, подхватывается при первом запуске, если в KV ещё пусто | Стартовый шаблон / демо |
| **3. KV напрямую** | Dashboard → Workers & Pages → KV → ключ `planer:{telegramUserId}` → JSON-поле `template` | Отладка, бэкап |
| **4. Локально** | Правка `tasks.example.txt` + очистка `localStorage` ключа `planer_store_v1` | Разработка без Telegram |

Рекомендуемый поток: один раз собрать код в блокноте → вставить через **«Код задач»** в мини-приложении.

## Интерфейс

- **Неделя** — день сверху (меню по стрелке), список задач, раскрытие подзадач стрелкой.
- Слева — режим редактирования (drag-and-drop), справа — быстрый переход на «Огонёк».
- Внизу — табы «Неделя» / «Огонёк».
- **MainButton «Добавить»** (Telegram) — модалка с полем ввода, задача вставляется **вверх** списка.
- **Огонёк** — счётчик серии + календарь текущей недели (оранжевый = выполнен, серый = нет / будущее).

### Огонёк — правила

За день должны быть выполнены все задачи `daily` + `weekly` (+ `once`, если есть на этот день).  
Списки с подзадачами считаются выполненными, когда закрыты **все** подзадачи.  
Если к началу нового дня вчерашний набор не закрыт — счётчик **сбрасывается в 0**.  
Полное закрытие дня даёт **+1** (один раз за дату).

## Деплой на Cloudflare Pages

1. Создайте KV namespace:
   ```bash
   npx wrangler kv namespace create PLANER_KV
   npx wrangler kv namespace create PLANER_KV --preview
   ```
2. Впишите `id` / `preview_id` в `wrangler.toml`.
3. В Cloudflare Dashboard → Pages → Create → подключите репозиторий (или загрузите папку).
   - Build command: *(пусто)*
   - Output directory: `/` (корень проекта)
4. Settings → Functions → KV bindings: имя `PLANER_KV` → ваш namespace.
5. В [@BotFather](https://t.me/BotFather): `/newapp` → URL вашего Pages-сайта.

Локально с Functions:

```bash
npx wrangler pages dev . --kv PLANER_KV
```

Без Worker данные живут в `localStorage` браузера — удобно для вёрстки.

## Telegram
